# ⚪ FLIPSHOT: Al-Kkagi Shooter"장기알에 담긴 탄환, 판을 뒤엎는 한 수"

알까기로 각을 재고, 슈팅으로 승부를 결정짓는 하이브리드 액션 게임

---

## 🎮 게임 소개
FLIPSHOT은 한국 전통 놀이인 **'알까기'**와 역동적인 **'슈팅 게임'**이 결합된 신개념 대전 게임입니다.

단순히 밀어내는 것에 그치지 않습니다. 내 장기알이 상대편 알을 타격하는 순간, 슈팅 게임로 전환됩니다.

알까기 실력으로 기회를 잡고, 슈팅 실력으로 상대를 밀어내세요!

---

# ✨ 주요 특징

## 🥢 알까기 모드 

(Strategy Phase)장기알을 조절하여 상대방의 알을 조준하고 발사합니다.

충돌하는 장기알 마다 슈팅모드에서의 능력이 달라집니다.

## 💥 슈팅 전환

(Action Phase)충돌 즉시 전환: 알과 알이 부딪히는 순간, 화면은 슈팅 게임으로 'Flip' 됩니다.

승패의 결과: 슈팅 대결에서 패배한 플레이어의 알이 밀려납니다(설령, 자신이 상대의 장기알을 쳤어도 되려 자신이 밀려날 수 도 있는거죠)

## 🛡️ 장기알 시스템

각 장기알(차, 포, 마, 상 등)마다 슈팅 모드에서의 기체 특성이나 탄환 패턴이 다릅니다.

---

# 🕹️ 게임 

프로세스단계플레이 방식핵심 목표

1. 조준 (Aim)장기알의 방향과 힘을 조절상대 알과의 충돌 각도 계산
   
3. 충돌 (Flip)알과 알이 부딪힘슈팅 모드 진입 트리거
   
5. 결투 (Shoot)실시간 탄막 슈팅 대결상대방을 밀어내거나 격파
   
  
* 알까기 물리 엔진 최적화슈팅 모드 전환 딜레이 최소화장기알별 기본 탄막 구현
